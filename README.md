# شبكة الصحفيين المستقلين في اليمن - ناقد

موقع CMS كامل (بايثون + SQLite، بلا مكتبات خارجية).

## ملفات المشروع (كلها في جذر المستودع)
| الملف | الدور |
|---|---|
| app.py | الخادم، قاعدة البيانات، لوحة الإدارة، المقالات، RSS، Sitemap |
| extra.py | الصلاحيات، المستخدمون، الوسائط، استيراد RSS، النشرة، SEO، النسخ الاحتياطي، المحرر |
| admin.py | لوحة التحكم الاحترافية (مؤشرات، مواد، محرر، نوافذ، وسائط، إعدادات) |
| theme.py | الشكل النهائي: القوائم المنسدلة، واجهة الأخبار، المقالة، أيقونات المشاركة |
| Dockerfile / render.yaml | النشر على Render |

## النشر على Render
1. ارفع **كل** الملفات أعلاه إلى جذر مستودع GitHub.
2. Render ← New ← Web Service ← اختر المستودع (Runtime: Docker). أو استخدم render.yaml عبر New ← Blueprint.
3. أضف متغير البيئة `YJN_ADMIN_PASSWORD` بكلمة مرور قوية (حساب المدير: admin).
4. أضف قرصاً دائماً (Disk) مساره `/data` — بدونه تضيع القاعدة والملفات المرفوعة عند كل نشر.
5. بعد التشغيل ادخل `/admin` وغيّر كلمة المرور، واضبط `base_url` في الإعدادات (يُملأ تلقائياً من رابط Render).

## التشغيل محلياً
    python3 app.py     # http://localhost:8000  — كلمة المرور تُطبع في الطرفية

## متغيرات البيئة
YJN_DB، YJN_UPLOADS، PORT، YJN_ADMIN_PASSWORD، YJN_BASE_URL

## النسخ الاحتياطي
لوحة التحكم ← النسخ الاحتياطي ← تنزيل. وانسخ مجلد uploads مع القاعدة.
